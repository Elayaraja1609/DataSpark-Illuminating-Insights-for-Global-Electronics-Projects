# DataSpark: Illuminating Insights for Global Electronics

## Project Overview
DataSpark is a comprehensive Data Analytics and Business Intelligence project focused on analyzing global electronics sales data. The project aims to uncover actionable insights related to customer behavior, product performance, sales trends, and store operations using Python, SQL, and Power BI/Tableau.

This project demonstrates an end-to-end data analytics workflow including:
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- SQL Database Management
- Data Visualization
- Business Insights & Recommendations

---

## Domain
Retail Analytics – Electronics Industry

---

## Problem Statement
As part of the analytics team for a global electronics company, the objective is to analyze large-scale sales and customer datasets to identify patterns, trends, and business opportunities.

The project focuses on:
- Improving customer satisfaction
- Optimizing sales performance
- Understanding product demand
- Enhancing operational efficiency
- Supporting data-driven business decisions

## Project Workflow

### 1. Data Collection
Collected multiple CSV datasets related to:
- Customers
- Products
- Sales
- Stores
- Exchange Rates

### 2. Data Cleaning & Preprocessing
Performed:
- Handling missing values
- Removing duplicates
- Data type conversion
- Date formatting
- Feature engineering

### 3. Database Creation
- Created MySQL database and tables
- Imported cleaned datasets into SQL
- Performed SQL queries for analysis

### 4. Exploratory Data Analysis (EDA)
Analyzed:
- Sales trends
- Revenue performance
- Customer purchasing behavior
- Product category performance
- Country-wise and store-wise sales

### 5. Dashboard Development
Built interactive dashboards using:
- Power BI

Dashboard highlights:
- Revenue KPIs
- Sales by Country
- Top Products
- Customer Insights
- Monthly Sales Trends
- Store Performance
